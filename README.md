Análisis de Comportamiento de Clientes ConnectaTel– Sprint 7
Este repositorio contiene el análisis realizado durante el Sprint 7 del Análisis de Comportamiento de Clientes ConnectaTel.

Los datasets /datasets/plans.csv, /datasets/users_latam.csv, /datasets/usage.csv incluyen 4,000 datos de usuarios con valores faltantes, centinelas, outliers y problemas de calidad diseñados para simular datos reales del Análisis de Comportamiento de Clientes ConnectaTel

📘 Cómo reproducir el análisis
Clona o descarga este repositorio.
Coloque los archivos planes.csv, users_latam.csv y use.csv en la misma carpeta que el notebook.
Ejecuta todas las celdas en orden desde la primera.
Los gráficos y resultados se generarán automáticamente.
🧠 Objetivo del análisis
Analizar el comportamiento de uso de clientes de ConnectaTel, empresa de telecomunicaciones con operaciones en México y Colombia, con el fin de:

Identificar patrones de uso de llamadas y mensajes. Detectar comportamientos atípicos o valores inusuales. Segmentar clientes según edad y nivel de consumo. Proponer recomendaciones comerciales para optimizar la oferta de aviones.
